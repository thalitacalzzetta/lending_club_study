Lending Club — Statistical Analysis

Project Overview

This project explores Lending Club loan data using Python and statistical analysis techniques.

The main objective is to investigate relationships between borrowers’ financial characteristics and loan interest rates, applying statistical concepts learned throughout my M.S. in Business Analytics program at San Francisco State University.

This project is part of my ongoing development in statistics, data analytics, and predictive modeling.

Project Status: Work in Progress

Research Questions

The analysis focuses on understanding:

* How do borrowers’ FICO scores relate to loan interest rates?
* Is revolving credit utilization associated with interest rates?
* Can we estimate loan interest rates using borrowers’ financial characteristics?
* How well does a multiple linear regression model explain variations in interest rates?

Dataset

Source: Lending Club Loan Data — Kaggle

The dataset contains information about loans and borrower characteristics.

The initial analysis focuses on three variables:

Variable	Description
fico	Borrower’s FICO credit score
revol_util	Revolving credit utilization
int_rate	Loan interest rate

Tools and Technologies

* Python: Data analysis and statistical modeling
* Pandas: Data cleaning and manipulation
* NumPy: Numerical operations
* Matplotlib: Data visualization
* Statsmodels: Regression analysis and statistical inference
* Spyder: Python development environment

Statistical Methods

The project currently focuses on:

* Exploratory Data Analysis (EDA)
* Correlation Analysis
* Multiple Linear Regression (OLS)
* Hypothesis Testing
* Statistical Significance
* Residual Analysis

Additional methods and model improvements will be incorporated as the project develops.

Project Development

This project is being developed progressively alongside my graduate statistics coursework.

The goal is to move from exploratory statistical analysis toward more advanced modeling techniques while documenting the analytical process, assumptions, and results.

Future Improvements

Planned improvements include:

* Evaluating regression assumptions
